# CPU-only torch — avoids pulling several GB of unused NVIDIA/CUDA packages,
# since this container has no GPU (bge_provider.py runs with use_fp16=False).
#
# 注意两件事（2026-09-16 实修，别再踩）：
#
# 1) 这里**必须**写 `torch==2.14.0+cpu`，不能写 `torch==2.14.0`。
#    阿里云 pytorch-wheels 镜像提供的是 `2.14.0+cpu` 这个带本地版本标识的
#    wheel。按 PEP 440，`==2.14.0` **不匹配** `2.14.0+cpu`（本地版本标识只有
#    在约束里显式带 `+` 时才参与匹配）。写 `2.14.0` 的后果实测是：第一层
#    已按 wheel 直链装好 2.14.0+cpu，到了这一层 pip 仍判为不满足，转而去
#    PyPI 下载 **554.6 MB 的 CUDA 版 torch**（镜像里根本用不上 GPU）。
#
# 2) 不要再写 `--extra-index-url`。
#    原来是 download.pytorch.org（国外源，国内 ~196MB 极慢、解析期频繁回查）；
#    改指 mirrors.aliyun.com/pytorch-wheels/cpu/ 也不行 —— 该镜像是目录索引式，
#    不是标准 PEP 503 索引，pip 无法从它解析 `+cpu` 版本。
#    正确做法：Dockerfile 用 wheel 完整 URL 直链安装（见 Dockerfile.local），
#    本文件这行只作为「已满足」的声明，不会再触发任何下载。
