毛利率 25.0%，较上年提升 0.9 个百分点；研发投入 1810 万元，同比增长 19.1%。

```python
def yoy(cur: int, prev: int) -> float:
    return (cur - prev) / prev  #  同比
```

上述计算口径与年报一致。
