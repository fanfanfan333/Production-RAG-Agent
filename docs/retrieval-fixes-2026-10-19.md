# 关键词独立召回与图关系校验修复

## 修改

- 关键词候选在最终文档校验之前独立收集。向量零命中不再提前结束检索，关键词命中的文档也不必先进入向量候选集。
- 向量、图和关键词文档 ID 的并集统一经过 PostgreSQL 文档状态、集合和权限校验；保留后续分片权限、元数据、融合和精排检查。
- 内存 BM25 缓存保留当前检索范围内的语料，不再按某次向量命中文档裁剪；容量上限和权限缓存分区不变，支持单分片语料。
- 图关系仍要求原文证据和明确的主谓宾顺序；否定与假设检查仅排除本次主谓宾匹配中的两个实体名称，不排除谓词或其余证据。

独立召回后融合的依据：[Qdrant 官方 Hybrid Search 说明](https://qdrant.tech/course/essentials/day-3/hybrid-search/)。继续使用现有 PostgreSQL/Qdrant，无新增依赖、接口或精排参数变更。
